# VeriSource Browser Extension - Privacy Policy

**Last Updated: November 21, 2024**

## Overview
VeriSource is committed to protecting your privacy. This extension verifies image authenticity by analyzing images you select.

## Data Collection

### What We Collect:
- **Image Data**: Images you choose to verify are sent to our servers for analysis
- **Image URLs**: The source URL of images you verify
- **Verification Results**: Analysis results are cached locally for 24 hours
- **Usage Statistics**: Number of verifications performed (stored locally)
- **Timestamps**: When verifications were performed

### What We DON'T Collect:
- Browsing history
- Personal information
- Cookies or tracking data
- Images you don't explicitly verify
- Passwords or credentials

## Data Usage
- Image data is used solely for verification analysis
- Results are cached locally in your browser for 24 hours
- Server logs retain IP addresses for 7 days for security purposes
- No data is sold or shared with third parties

## Data Storage
- **Local Storage**: Verification results cached for 24 hours, then auto-deleted
- **Server Storage**: Images analyzed in real-time, not permanently stored
- **Logs**: Server logs retained for 7 days for security and debugging

## Data Security
- All communication uses HTTPS encryption
- Images from private networks (localhost, 192.168.x.x) are blocked
- No authentication required - we don't store user accounts
- Maximum file size limit: 10MB

## Your Rights
- **Access**: View cached data in chrome://extensions → VeriSource → Storage
- **Deletion**: Clear cached data anytime via extension settings
- **Opt-out**: Uninstall extension to stop all data collection

## Third-Party Services
We use:
- Railway.app for hosting (see their privacy policy)
- No analytics or tracking services

We'll notify users of material changes via extension updates.
