# VeriSource Browser Extension

Chrome extension for instant AI image detection.

## Installation
1. Open Chrome: `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select this folder

## Files
- manifest.json
- background.js
- content.js
- popup.html
- popup.js
- styles.css
- icons/ (placeholder - replace with real icons)

## Usage
Right-click any image → "Verify with VeriSource"
